# 丹青词境

一个模型接入版 Web 应用，支持两条创作链路：

- 上传若干参考图片，连同所选绘画名家预设一起发送给模型，先做视觉风格抽取，再生成一张新的图片。
- 上传若干诗词文本，连同所选著名诗词人预设一起发送给模型，先做诗风归纳，再生成一首新的诗词。
- 输入画家或诗词人姓名后，应用会联网检索人物条目与代表作，并把这些代表作作为新的风格参考参与生成。
- 支持保存风格模板、查看最近生成历史；图片结果支持 PNG 导出与缩略图画廊回看。
- 联网检索会先返回多个候选人物，用户可手动点选最合适的画家或诗词人，再加载其代表作。
- 模板和历史都支持一键清空，生成历史还支持单条删除。
- 联网检索内置服务端内存缓存；重复查询同一人物时，会优先复用候选列表和百科资料，减少外网请求。

## 运行方式

1. 复制 `.env.example` 为 `.env`。
2. 在 `.env` 中填写国内可访问供应商的密钥。
3. 启动服务：`npm start`
4. 打开浏览器访问 `.env` 中 `PORT` 对应的地址；示例默认是 `http://localhost:3000`，当前本地工作区配置为 `http://localhost:3017`

也可以直接使用根目录脚本：

- `./start.sh`：后台一键启动服务，并把 PID 和日志写入 `.runtime/`
- `./stop.sh`：停止当前后台服务，并清理 PID 文件
- `./restart.sh`：停止当前服务后重新启动

这些脚本会优先识别目标端口上是否已经跑着当前项目的 `server.js`。如果服务已在运行但 PID 文件丢失，会自动接管并恢复管理；如果端口被其他程序占用，会直接提示冲突而不是重复启动失败。

## 环境变量

- `TEXT_PROVIDER`: 文本模型供应商，默认 `deepseek`。
- `TEXT_API_KEY`: 文本模型专用密钥；如为空，会尝试读取对应供应商密钥。
- `TEXT_BASE_URL`: 文本模型接口地址；默认随供应商自动填充。
- `TEXT_MODEL`: 文本模型名称；默认随供应商自动填充。
- `IMAGE_PROVIDER`: 图片模型供应商，默认 `bailian`。
- `IMAGE_API_KEY`: 图片模型专用密钥；如为空，会尝试读取对应供应商密钥。
- `IMAGE_BASE_URL`: 图片模型接口地址；默认随供应商自动填充。
- `IMAGE_MODEL`: 图片模型名称；默认随供应商自动填充。
- `DEEPSEEK_API_KEY`: DeepSeek 密钥，可供 `TEXT_PROVIDER=deepseek` 使用。
- `SILICONFLOW_API_KEY`: 硅基流动密钥，可供 `IMAGE_PROVIDER=siliconflow` 或 `TEXT_PROVIDER=siliconflow` 使用。
- `BAILIAN_API_KEY`: 百炼密钥，可供 `TEXT_PROVIDER=bailian` 或 `IMAGE_PROVIDER=bailian` 使用。
- `PORT`: 可选，默认 `3000`。

## 当前实现说明

- 图片模式：后端会先让多模态文本模型读取“名家预设 + 用户样本图 + 联网检索到的人物与代表作 + 提示词”，输出结构化风格摘要，再把摘要送给图片模型生成结果。
- 诗词模式：后端会让文本模型读取“词人预设 + 用户样本文本 + 联网检索到的人物与代表作 + 提示词”，输出风格总结与新诗词。
- 默认配置不再指向 OpenAI，而是走国内可访问的组合：文本分析与诗词生成默认使用 DeepSeek，图片生成默认使用百炼 `wanx2.1-t2i-turbo` 异步任务接口；硅基流动仍可作为备用图片供应商。
- 风格模板：前端支持把当前“预设 + 联网参考”保存为本地模板，下次可直接套用。
- 生成历史：图片模式保存最近作品的缩略图画廊；诗词模式保存最近作品的标题、正文与风格摘要。
- 检索缓存：`/api/style-lookup` 会按“模式 + 姓名 + 候选人物”做 TTL 缓存，并缓存外部百科 JSON 响应，避免重复访问 Wikidata / Wikipedia。
- 学习方式：这里的“学习风格”是运行时少样本风格抽取，不是参数微调或长期训练。

## 目录

- `server.js`: 零依赖 Node 服务端，负责静态资源和模型 API 调用。
- `app.js`: 前端交互逻辑，负责样本上传、预设选择与结果展示。
- `index.html` / `styles.css`: 页面结构和视觉样式。
