# 丹青词境

丹青词境是一个面向中文创作场景的双模态生成应用：同一套工作台里，既可以学习绘画风格生成新图像，也可以学习诗歌文体生成新作品。它把内置名家预设、用户上传样本、联网检索到的人物代表作，统一压成一次运行时的风格抽取，再把抽取结果送给模型生成最终内容。

默认配置优先使用中国大陆可稳定访问的模型供应商：文本链路为 DeepSeek，图像链路为阿里百炼 `wanx2.1-t2i-turbo`，并保留硅基流动作备用选项。

![丹青词境首页总览](./89050d62-b104-41c0-94b2-51bd367d6715.png)

## 核心能力

- 图像生成：选择绘画大师、动画导演或国际视觉风格，叠加参考图片与联网代表作后生成新图像。
- 诗词生成：选择中外诗人风格，叠加诗词样本与联网参考后生成新作；海外语言作品会自动附中文翻译。
- 联网参考：输入艺术家姓名后，系统会检索人物条目、代表作与摘要，并自动判断应该落到图像还是诗词模式。
- 文体识别：在诗词链路中，系统会继续细分为诗、词、俳句等文体，并按对应格式约束模型输出。
- 历史与模板：支持保存当前风格组合为模板；图片和诗词都保留生成历史，方便回看与复用。
- 本地运行友好：根目录提供 `start.sh`、`stop.sh`、`restart.sh`，处理端口占用、PID 丢失和后台管理。

## 工作方式

### 图像链路

1. 选择画家、动画大师或视觉风格预设。
2. 可选上传多张参考图片，补充色彩、质感、构图和笔触信息。
3. 可选输入人物姓名，联网获取条目和代表作，作为额外风格参考。
4. 服务端先调用文本模型总结结构化视觉风格，再把摘要交给图像模型生成结果。
5. 前端支持 PNG 导出、缩略图画廊和历史记录。

### 诗词链路

1. 选择诗人或词人预设，并可上传本地诗词样本。
2. 输入人物姓名后，系统会联网抓取其条目与代表作。
3. 如果检索结果属于诗词链路，系统会进一步识别是诗人、词人还是俳人。
4. 服务端按对应文体约束生成，例如：
	- 诗人：生成诗体内容。
	- 词人：生成词体内容，强调长短句、词牌名或词题。
	- 俳人：生成高度凝练的短诗或俳句。
5. 若输出语言不是中文，系统会附上逐行中文翻译。

## 快速开始

### 运行环境

- Node.js 18 及以上
- 一个可用的文本模型密钥
- 一个可用的图像模型密钥

### 安装与启动

1. 复制配置文件。

```bash
cp .env.example .env
```

2. 在 `.env` 中填写密钥和模型配置。

3. 启动服务。

```bash
npm start
```

4. 打开浏览器访问：

```text
http://localhost:3017
```

也可以使用根目录脚本：

```bash
./start.sh
./stop.sh
./restart.sh
```

这些脚本会优先检查目标端口上是否已经运行当前项目的 `server.js`。如果服务已在运行但 PID 文件丢失，会自动接管；如果端口被其他程序占用，会直接提示冲突。

## 环境变量

### 文本模型

| 变量 | 说明 |
| --- | --- |
| `TEXT_PROVIDER` | 文本模型供应商，默认 `deepseek` |
| `TEXT_API_KEY` | 文本模型密钥 |
| `TEXT_BASE_URL` | 文本模型接口地址 |
| `TEXT_MODEL` | 文本模型名称 |
| `TEXT_ENDPOINT_PATH` | 文本模型接口路径，默认 `/chat/completions` |

### 图像模型

| 变量 | 说明 |
| --- | --- |
| `IMAGE_PROVIDER` | 图像模型供应商，默认 `bailian` |
| `IMAGE_API_KEY` | 图像模型密钥 |
| `IMAGE_BASE_URL` | 图像模型接口地址 |
| `IMAGE_MODEL` | 图像模型名称 |
| `IMAGE_ENDPOINT_PATH` | 图像模型接口路径 |

### 供应商密钥与端口

| 变量 | 说明 |
| --- | --- |
| `DEEPSEEK_API_KEY` | `TEXT_PROVIDER=deepseek` 时可直接使用 |
| `BAILIAN_API_KEY` | `TEXT_PROVIDER=bailian` 或 `IMAGE_PROVIDER=bailian` 时可使用 |
| `SILICONFLOW_API_KEY` | `TEXT_PROVIDER=siliconflow` 或 `IMAGE_PROVIDER=siliconflow` 时可使用 |
| `PORT` | 服务端口，示例默认值为 `3017` |

| 路径 | 说明 |
| --- | --- |
| `server.js` | Node.js 服务端，负责静态资源、联网检索、模型调用与输出规整 |

## 当前实现细节

- 图像生成不是直接把提示词送给图片模型，而是先由文本模型抽取视觉风格摘要，再二次生成。
- 诗词生成会综合预设、上传样本、联网人物和提示词，生成结构化 JSON 结果后再在前端展示。
- 联网检索带有服务端内存缓存，重复查询会优先复用已获取的候选人物和百科数据。
- “学习风格”属于运行时少样本风格抽取，不是模型微调，也不会长期训练用户私有权重。
- 本地数据如模板和历史主要保存在浏览器本地存储中，适合单机演示和轻量使用。

## 适用场景

- 做一个可展示的 AI 创作工作台 Demo
- 快速验证“名家风格 + 样本 + 联网参考”混合生成流程
- 体验中外诗歌风格迁移与图像风格迁移
- 作为后续接入账号系统、数据库和任务队列前的单机原型
